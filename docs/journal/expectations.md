# Expectations

What is not yet proven, and what would prove it wrong.

| Expectation | What would prove it wrong | How to check |
| --- | --- | --- |
| The **Report a vulnerability** button that [`SECURITY.md`](../../SECURITY.md#reporting-a-vulnerability) describes works once the repository is public and the setting is on. | An account with no role in the repository opens the Security tab and sees no button, or the button does not open a private report form. | Open the Security tab from such an account. |
| `just` and the C and C++ tests pass on a clean checkout. This project's maintainers have no record of running them since it split from Meta's original repository, and no workflow runs them. | After the [Quick Start](../../README.md#quick-start) steps, `just` exits with a non-zero status. | Run `just` from the repository root, with `just`, CMake, a C/C++ compiler and Rust installed. |
| Every link from the navigation block into Haptics Studio and Haptics Studio Examples opens a page once their working branches reach `main`. Studio's Design & Integration, Source Code and Architecture pages are not on its `main` yet, so those three links lead to a missing page until then; [basslet/haptics-studio#32](https://github.com/basslet/haptics-studio/issues/32) accepts that. Design & Integration also needs [basslet/haptics-studio#44](https://github.com/basslet/haptics-studio/pull/44), which moves its page to a new path. The lint does not open web links. | After those merges, a link in the block at the top of [`README.md`](../../README.md) that leads to another repository opens a missing page. | Open each `https://github.com/basslet/` link in that block, signed in while the repositories are private. |
| The README banner shows `resources/images/logo/Banner-SDK-dark.png` in GitHub's dark theme and `resources/images/logo/Banner-SDK-light.png` in the light theme, 800 pixels wide. The two files look alike, except that the wordmark is a lighter grey in the dark one. | In a window wider than 800 pixels, the banner is another width, shows no image, or loads the other theme's file. | Open the repository page on GitHub in each theme, signed in while the repository is private. Open the banner image in a new tab and read its file name, and check its width. |
| `node scripts/doc_nav.js --compare` names every repository whose copy of the shared files on `main` differs, as [decisions.md](decisions.md) says, once all three repositories have the files on `main`. Until then it stops at the first copy it cannot read and compares nothing: on 2026-11-12 it printed `haptics-studio: scripts/doc_nav.js on main cannot be read: gh: Not Found (HTTP 404)` and exited 1. | After the three integration branches reach `main`, `--compare` still stops at a copy it cannot read, or exits 0 while a copy differs. | Run `node scripts/doc_nav.js --compare`, signed in to `gh` while the repositories are private. Then compare each repository's copy on `main` directly: `gh api repos/basslet/<repository>/contents/scripts/<file> --jq .sha` gives the same value in all three repositories for each of the four files exactly when `--compare` should exit 0. |
